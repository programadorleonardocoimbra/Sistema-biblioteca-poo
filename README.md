# 📚 Sistema de Gerenciamento de Biblioteca

Projeto desenvolvido em Java com o objetivo de praticar e demonstrar
os principais conceitos de Programação Orientada a Objetos.

## 🚀 Tecnologias

- Java 21
- Maven
- IntelliJ IDEA
- Git
- GitHub

## 🧠 Conceitos aplicados

- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Enum
- Collections
- Tratamento de Exceções
- Separação de responsabilidades

## 📋 Funcionalidades

- Cadastro de livros
- Cadastro de usuários
- Listagem de livros
- Listagem de usuários
- Empréstimo de livros
- Devolução de livros
- Controle de disponibilidade
- Histórico de empréstimos
